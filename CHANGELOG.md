# Changelog

All notable changes to **OrgExplorer** are documented in this file.

This project follows a versioned release history. Features listed below describe the initial public release.

## [1.0.0](https://github.com/AOSSIE-Org/OrgExplorer/releases/tag/v1.0.0) - 2026-10-25

### Added
- Organization overview with key GitHub organization and repository information.
- Repository insights, including stars, forks, watchers, and activity metrics.
- Contributor analytics to explore contributions across repositories.
- Repository comparison and ranking using repository metrics.
- Interactive charts and visualizations for exploring organization data.
- GitHub REST API integration for public organization and repository data.
- Optional GitHub Personal Access Token (PAT) support for authenticated, GraphQL-powered insights.
- Organization and repository navigation for exploring related data.
- Dark mode support.
- Persistent organization selection.

### Notes
- This is the first public release of OrgExplorer.
- Future releases may expand analytics, visualizations, and user-requested features.
